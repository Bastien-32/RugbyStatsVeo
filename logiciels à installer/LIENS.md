# Logiciels à installer

Ces logiciels ne sont pas fournis avec le projet : ils se téléchargent
sur le site de leur éditeur, qui en distribue toujours la version à jour.

## VLC media player

Nécessaire pour dépouiller une vidéo enregistrée sur votre ordinateur.
Inutile si vous travaillez uniquement sur des vidéos Veo dans Chrome.

- macOS : <https://www.videolan.org/vlc/download-macosx.html>
- Windows : <https://www.videolan.org/vlc/download-windows.html>

Prendre la dernière version stable. Le projet a été mis au point avec
la version 3.0.23.

> **macOS** : ne lancez pas VLC vous-même avant d'ouvrir Excel. Utilisez
> toujours le bouton **Connecter lecteur vidéo**, qui démarre VLC avec la
> configuration attendue par VeoVideoControl.

## Google Chrome

Nécessaire pour dépouiller une vidéo hébergée sur Veo.

- <https://www.google.com/chrome/>

L'extension qui relie Chrome au classeur se trouve dans le dossier
**VeoVideoControl/Extension**. Son installation est décrite dans
INSTALLATION.md.

## Microsoft Excel

Le classeur demande Excel 2019, 2021 ou Microsoft 365, sur Windows ou
macOS, avec la prise en charge des macros VBA.

Les versions web, iPad et Android n'exécutent pas les macros : elles
ouvrent le classeur mais aucun bouton n'y fonctionne.
